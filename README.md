# Yolanda Portfolio — Modern Edition 🌸

Portfolio personal Yolanda Yudis Prastica, XI RPL A.

## File
- `index.html` — konten/struktur
- `style.css` — desain dan responsive layout
- `script.js` — interaksi
- `assets/profile.jpg` — foto profil
- `assets/heaven-song.mp3` — musik

## Menjalankan
Buka folder project di Antigravity IDE lalu buka `index.html` di browser. Live Server juga dapat digunakan.

## Mengganti foto
Ganti `assets/profile.jpg` dengan foto sendiri. Pertahankan nama file tersebut.

## Mengganti musik
Ganti `assets/heaven-song.mp3`. Musik tidak autoplay; pengguna harus menekan Play. Jika file belum tersedia, website tetap berjalan.

## Mengganti warna
Edit variabel warna di bagian `:root` pada `style.css`.

## Mengganti profil
Edit teks langsung di `index.html`.

## Mengganti GitHub
Jangan gunakan username palsu. Cari `[username GitHub]` di `index.html`, lalu ganti dengan username/link asli.

## Mengganti skill
Cari `data-progress="80"` dan nilai persentasenya di `index.html`.

## Deploy
### GitHub Pages
Upload folder ke repository GitHub → Settings → Pages → pilih branch utama → Save.

### Netlify / Vercel
Hubungkan repository atau upload project, lalu gunakan folder project sebagai root.

## Catatan
Website menggunakan HTML/CSS/JavaScript vanilla agar mudah dipelajari dan diedit. Tidak menggunakan framework berat.
